# Лабораторные работы по PHP.
## 1. Инструкции по запуску проекта
1. Скачайте проект и разместите файлы в директории веб-сервера:
`git clone https://github.com/randy525/PHP-Lab.git`
2. Запустите сервер:
   `php -S localhost:8000`
4. Откройте в браузере:
   `http://localhost:8000`
## 2. Краткая документация к проекту 
Лабораторные работы раскинуты по папкам `lab1, lab2, lab3` и т. д.
В папке с выполненной лабораторной работы задания раскинуты по папкам `task1, task2, task3` и т. д.
Код находится в файле `index.php`
