## 5. Ответы на контрольные вопросы

1. Объясните, что такое глобальные переменные $_POST и $_SERVER["PHP_SELF"]  
$_POST - Это суперглобальный массив в PHP, который содержит данные, отправленные из формы методом POST.  
$_SERVER['PHP_SELF'] -Это путь к текущему файлу. Используется, чтобы форма отправлялась сама на себя.
  
2. Объясните, чем отличаются глобальные переменные $_REQUEST и $_POST.  
$_POST - Содержит данные, переданные методом POST. Используется строго для форм с method="POST".  
$_REQUEST - Объединяет $_GET, $_POST, и $_COOKIE. Используется, если не важен источник данных.  
Рекомендуется использовать $_POST при работе с формами, так как он более предсказуем и безопасен.
